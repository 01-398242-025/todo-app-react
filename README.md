# Todo App

A modern, responsive todo application built with React, TypeScript, Tailwind CSS, and shadcn/ui components.

### Landing Page
![Landing Page](/public/landing_page.png)

### ✨ Features
Add, Edit, and Delete Todos
Easily manage your daily tasks with intuitive controls.
Filter Todos
View all, active, or completed tasks with a single click.
Task Completion Stats
Instantly see how many tasks are completed and how many remain.
Responsive Design
Fully optimized for mobile, tablet, and desktop devices.
Reusable Components
Built with modular React components for easy maintenance and scalability.
TypeScript Support
Type-safe codebase for better reliability and developer experience.
Custom Hooks
Utilizes React hooks for state and effect management.
Modern UI
Styled with Tailwind CSS and a rich set of UI components for a clean, modern look.
Fast and Lightweight
Powered by Vite for instant loading and smooth performance.
404 Not Found Page
Friendly error page for invalid routes.

## Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. ## Clone the repository:
```bash
git clone <repository-url>
cd todo-app-react
```

2. ## Install dependencies:
```bash
npm install
```

4. ## Open your browser and navigate to
 ➜  Local:   `http://localhost:8080/`
 ➜  Network: `http://192.168.214.198:8080/`
